# Ворота: что уже посмотрено и подтверждено

Файл читает `npm run stage`. Пункт ворот, который смотрят глазами, отмечается
здесь — с датой и словом того, кто смотрел. Иначе он спрашивается заново
каждую сессию: память сессии кончается вместе с сессией, а файл — нет.

Отмечается строкой `- [x]`, и в ней обязан стоять **текст пункта целиком**.
Переписали пункт — подтверждение лапается: другой вопрос требует другого
ответа.

## 0 · Основание

- [x] 21.09.2026 · исполнитель · палитра и шкалы отрисованы и просмотрены на обеих темах
      — стенд `npm run scale:stand`, оба кадра, светлая и тёмная, 390 и 1440;
      снимки показаны заказчику.
- [ ] набор цвета показан заказчику отрисованным — не кодами, а кнопкой, которую он нажал
      — 21.09.2026 отметка снята как неверная. Заказчик сказал «подтверждаю»,
      а следом спросил: «что такое стенд цвета?» — то есть ему его ни разу не
      показывали, и подтверждать было нечего. Стенд собран в тот же день
      (`npm run palette:stand`, семь наборов на одной карточке товара);
      отмечать пункт — когда заказчик назовёт набор.
