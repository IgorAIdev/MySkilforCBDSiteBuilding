# Ворота: что уже посмотрено и подтверждено

Файл читает `npm run stage`. Пункт ворот, который смотрят глазами, отмечается
здесь — с датой и словом того, кто смотрел. Иначе он спрашивается заново
каждую сессию: память сессии кончается вместе с сессией, а файл — нет.

Отмечается строкой `- [x]`, и в ней обязан стоять **текст пункта целиком**.
Переписали пункт — подтверждение лапается: другой вопрос требует другого
ответа.
