# Переносимое ядро мастерской · 22.09.2026

Из CBD выделен исполняемый общий механизм, не копия брендового сайта.
Источник: `skills/site-building/assets/studio`. Он использован в отдельном
проекте «Север» на plain JavaScript и подключён обратно к React/Next CBD через
местный адаптер. Процесс интеграции описан в `references/studio-runtime.md` скилла.

## Причины исправлений

- Механизмы прежде оставались в CBD; теперь они поставляются и реально используются.
- Версия документа была ручной; теперь читается из снимка.
- У MD/PDF были разные содержательные шаблоны; теперь один текст.
- Завершение долгого экспорта могло применить уже изменённый draft; сравнивается
  захваченный снимок, а ошибка сохранения не меняет applied/approved.
- Коррекции palette/scale из CBD возвращены в набор. Новая текстовая роль
  нажатия также добавлена в реестр имён и лист образцов: исправлены потребители,
  а не ослаблены проверки.
- Старый update затирал местные tools; теперь выводит конфликты до записи.
  В CBD инструменты массово не заменялись.
- В браузере CBD Next нормализовал 127.0.0.1 в localhost. Same-origin теперь
  проверяется по реальному Host с локальным allowlist; forwarded не доверяется.
  Чужие сайты, порты и некорректные Host тестами отклоняются.

## Проверки и ограничения

Локально пройдены npm test; check:rules/skill/css/code/port/scale/palette; pro:check;
studio:check; 12 специальных unit-тестов ядра; проверки установщика; валидатор
SKILL.md; браузерный пилот; CBD typecheck/test/lint/build и сборка чистого экспорта.
В CI добавлен тот же пилот на Ubuntu в runner.temp. Существующие компонентные
проверки и Lighthouse CI сохранены. Результаты облачной проверки смотреть в PR.

Все страницы PDF отрисованы, контактные листы и страницы типографики/передачи
просмотрены. Для CBD viewport-снимки предпочтительнее full-page: существующий
content-visibility:auto не отрисовывает далёкие карточки до прокрутки к ним.

Не заявлено: миграция любой неизвестной схемы, готовые WP/OpenCart темы,
реальная оплата, production CMS, полный WCAG/диктор/все браузеры. Увеличение
корневого текста не равно отдельному тесту browser zoom. SHA идентифицирует
содержимое, но не является цифровой подписью. Исследования и лицензии сохранены.
Готовность каждого будущего сайта нужно проверять отдельно.

До переноса CBD сохранён локальным коммитом `118fccb`. Мастерская не очищалась.
Порт 3030 и браузерные настройки владельца тестами не затрагивались.
