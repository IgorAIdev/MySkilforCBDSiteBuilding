# Вид витрины шаблона

Опубликованный вид витрины шаблона — то, что заказчик выбрал в панели вида
на демо-витрине 25.09.2026: палитра «Тёплый лист», шрифт Manrope, ритм
«Тесный», отметка текущей полки «Pill»; остальное — умолчания каталога.

- `look.json` — опубликованный вид (имена выбора и значения);
- `fonts/` — файлы шрифта этого вида (Manrope, SIL Open Font License).

`npm run storefront` при новой постановке кладёт этот вид в витрину
`.storefront/` и пересчитывает им стили. Шаблон его не везёт: витрина,
поставленная установщиком, встречает видом по умолчанию (docs/decisions.md).
Выбрали в панели витрины `.storefront/` другое и опубликовали —
`npm run storefront -- --save-look` кладёт вид сюда, дальше — коммит.
