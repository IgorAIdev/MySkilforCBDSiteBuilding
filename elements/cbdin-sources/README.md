# Исходники cbdin.bg для элементов 11–15 и 64

## Почему они здесь

Взяты по прямому слову заказчика 24.09.2026, приложив снимки страницы
дизайн-системы cbdin.bg/bg/design: «в проекте cbdin.bg есть иконки и кнопки
оттуба можешь в нашу базу вытянуть полезного».

Это исключение из решения `docs/decisions.md`, «Порядок работ»: «Старый
магазин cbdin образцом не считается … Из него берутся данные и логика
магазина …, не вид и не числа вёрстки». Исключение узкое:

1. отсюда берутся только кандидаты в элементы на выбор — знак «куда ведёт»
   в четырёх одеждах (11–14), лист значков (15) и карточка товара полки (64,
   по слову заказчика 24.09.2026: «это из cbdin.bg может скопировать оттуда
   можешь»);
2. каждый кандидат приведён к единой форме набора (И337, И338): числа
   набора, краски — роли палитры набора, значки органов — из листа набора;
   чисел и красок cbdin в отрисовках нет;
3. в сайт и в панель вида ничего из этого не попадает, пока заказчик не
   выберет (И336); образцом вида и чисел вёрстки cbdin по-прежнему не
   считается.

## Что лежит

- `design-signs.png`, `design-icons.png` — снимки страницы дизайн-системы
  cbdin.bg/bg/design, присланные заказчиком;
- `go.module.css` — модуль одежд знака «куда ведёт», копия
  `D:/Bussiness_Project/cbd_ecommerce_eu/apps/cbdin/styles/go.module.css`;
- `Icons.tsx` — лист значков, копия `…/apps/cbdin/components/Icons.tsx`;
- `ProductCard.tsx`, `ProductCard.module.css`, `BuyBtn.module.css` — карточка
  товара полки и её кнопка «в корзину», копии `…/apps/cbdin/components/`;
  снимки товаров к элементу 64 — `…/apps/cbdin/public/shots/`;

все копии — с коммита d4f1eb7 репозитория cbd_ecommerce_eu. Это справка
к отрисовкам, ничто их не подключает.
