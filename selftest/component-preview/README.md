# Изолированная проверка выбранных компонентов

Этот стенд импортирует настоящие исходники из `skills/site-building/assets`,
а не их демонстрационные копии. Он не устанавливается в сайты и не означает
утверждение дизайна CBDstorefront. Его нейтральные цвета — только тестовые данные.

В этой папке: `npm ci`, `npm run typecheck`, `npm run build`, `npm run verify`.
Также `npm run lighthouse`: три прогона с бюджетами, HTML/JSON в
`dist/lighthouse-reports` внутри этой папки. Ненулевой код — нарушение, не успех.
Локальный verify использует установленный Chrome. В CI устанавливается Chromium
через Playwright. Результаты и снимки сохраняются в корневой `dist/component-review`.
CI публикует эту папку как artifact. Не коммитить зависимости и собранный bundle.

Проверяются действия кнопки, меню с клавиатуры, Escape и возврат фокуса,
немодальный режим, checkbox, раскрытие навигации, загрузка восьми SVG,
отсутствие горизонтального переполнения и ошибок JS на 375 и 1280 px.
Снимки светлой/тёмной темы делаются после завершения CSS-переходов.

Это не полный WCAG-аудит: screen reader, все браузеры, все комбинации состояний,
реальная CMS/корзина, серверные React-границы и длинный контент сайта проверяются
при интеграции. Vite предупреждает об `use client`: fixture — клиентский SPA;
директива сохранена в исходниках для соответствующего React-фреймворка.
