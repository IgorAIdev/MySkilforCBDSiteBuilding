# Оси — слой 2 основания

Разбор к разделу «Оси» закона `craft`. По каким обстоятельствам одно имя
получает разные значения, чем каждая ось включается, что по ней меняется,
а что нет — и чем это меряется. Реестр — `tools/axes.mjs`; семьи
`axisUnknown`, `axisTheme`, `axisScope`, `axisHover` в `check:css`.
Пересмотрено 20.09.2026 против сырых ответов исследования
(`raw/findings/next-steps/next_theming.json`, `next_responsive.json`,
`next_multilingual-text.json`, `site-steps/steps_foundations-carbon-spectrum-atlassian.json`,
`steps_token-tiers.json`).

Содержание: сначала оси, потом значения · реестр осей (из кода) · тема ·
указатель · ширина · язык · движение · контраст · что нашёл замер
20.09.2026 · что решено иначе, чем у первоисточников · чего не делает.

## Сначала оси, потом значения

Spectrum ставит Platform scale и Theming сразу после Design tokens:
«сначала решают, что мобильный экран в 1.25 раза крупнее, и только потом
рисуют шрифты и кнопки». Значение токена — набор по осям тема × указатель ×
локаль, а не одно число. React Spectrum: «All React Spectrum applications
start with a Provider» — тема, colorScheme, scale, locale в корне. Слой
готов, когда «перечислены оси и для каждого семейства записано, по каким
осям оно меняется»; переключение оси не трогает ни один узел: Carbon —
«Each theme shares the same variables and roles, with only the value
changing».

## Тема

- Переключатель — одно свойство `color-scheme` на `<html>`; `[data-theme]`
  из cookie ставит только его; без cookie — `light dark`, телефон решает
  сам. Ноль инлайн-скриптов (next_theming, правило 0).
- Цвет объявлен один раз функцией `light-dark()`, не двумя блоками;
  Baseline low 2024-05-13 (Chrome 123, Firefox 120, Safari 17.5).
- С темой меняется только цвет: тень несёт `light-dark()` внутри, вуаль —
  `color-mix()`, не `filter: brightness()`.
- Тёмная полоса — `color-scheme: dark` на самой полосе; системные элементы
  (скроллбар, поля, `<dialog>`, `::backdrop`) красит `color-scheme`, не рука
  — «Ручная раскраска скроллбара (`scrollbar-color`) … до Baseline —
  вместо `color-scheme`» назван антипаттерном.
- Объявленный `color-scheme: light dark` — защита от «авто-тёмного» Chrome
  Android и Samsung Internet (Румыния: Chrome 76.82 %, Safari 15.05 %;
  Хорватия: Chrome 63.56 %, Safari 27.23 % — StatCounter, 08.2026).
- Три состояния проверяются (без cookie + тёмная ОС, cookie light, cookie
  dark) — расхождение значит, что токен записан вторым блоком.

## Указатель

- `@media (pointer: coarse)`: цель 44, зазор между целями 16 (Primer
  `control.minTarget` fine 16 / coarse 44; WCAG 2.5.8 пол 24). Надёжнее
  `any-pointer: coarse` — палец у планшета с трекпадом никуда не делся.
- `:hover` только внутри `@media (hover: hover)`: на тачскрине наведение
  «залипает» после касания; ответ на касание — `:active`, сразу.
- pointer и hover — эвристики о главном устройстве, не факт (Firefox на
  ноутбуках с трекпадом годами отдавал `pointer: coarse`): по ним меняют
  размер цели и отклик, но не прячут содержимое и не переключают раскладку.
- Spectrum: под пальцем компоненты крупнее в 1 : 1.25 (149 из 340 токенов
  раскладки и 36 из 72 типографских имеют наборы desktop / mobile), а
  spacing и border-width статичны.

## Ширина

Не ось значений, а ось рамп: строитель шкал ведёт ступень между двумя
названными ширинами; три шва — там, где меняется смысл раскладки; узел
меряет контейнер. Carbon FAQ: «the tokens themselves do not change values
based on the screen size … acceptable at page breakpoints to jump a step».

## Язык

- `<html lang>` из адреса — условие для переносов, кавычек, спецкейсинга,
  шрифта и чтения вслух (W3C qa-lang-why); текст на другом языке внутри
  страницы получает свой `lang`.
- Перенос: `overflow-wrap: anywhere` обязателен (учитывается в min-content,
  ячейка не растянется), `<wbr>` для «20%CBD+CBN», `hyphens: auto` — только
  улучшение: у Chromium нет словаря переноса для румынского (`hyph-ro.hyb`
  нет ни в 118, ни в main на 20.09.2026), для хорватского и итальянского
  есть.
- Кавычки — по языку страницы: hr и ro „…“, it «…», en "…" — `quotes: auto`
  (Chrome 87+, Firefox 70+, Safari 14.1+).
- `text-size-adjust: 100%` — iOS Safari в альбоме раздувает текст сам.
- Расширение при переводе: до 10 знаков — до 300 %, 11–20 — 200 %, 21–30 —
  180 %, 31–50 — 160 %, 51–70 — 140 % (второй ответ агента: 151–170 %),
  свыше 70 — 130 % (W3C / IBM).
- Числа и валюта — два независимых параметра `Intl`, не одна строка
  локали; у итальянской локали группировка тысяч с пяти знаков — это CLDR,
  не ошибка.
- Словарь токенов не переводится: «Spectrum tokens are not localized».

## Движение

`@media (prefers-reduced-motion: reduce)` гасит длительности и плавную
прокрутку; смысл на движении не держится. Carbon: «Is your motion
purposeful? responsive? meticulous? unobtrusive?».

## Контраст

- `prefers-contrast: more` (iOS «Увеличить контраст», Windows; Baseline
  high 2024-11-30) усиливает существующие роли, а не рисует вторую тему:
  волосок → сплошной, приглушённые чернила → основные, вуаль → заливка.
  Один блок в токенах, не в узлах.
- `forced-colors: active` (Windows High Contrast; медиазапрос Baseline
  high 2025-03-12): 16 цветовых свойств заменяются палитрой пользователя,
  тени и градиенты стираются, выживают обводки и `outline`. Поэтому у листа
  и органа — обводка, у знака — `currentColor`, у фокуса — `outline`
  системным `Highlight`; `forced-color-adjust: none` — только для образца
  цвета, никогда для текста и кнопок.

## Что нашёл замер 20.09.2026

- Тема и наведение держались верно: `[data-theme]` ставит только
  `color-scheme`, `prefers-color-scheme` в стилях нет, `light-dark()` — 120
  объявлений, `:hover` вне `(hover: hover)` — ноль.
- **Языка не было**: ни `overflow-wrap`, ни `hyphens`, ни `quotes`, ни
  `text-size-adjust` — при четырёх языках магазина и румынском без словаря
  переноса.
- **Контраста не было**: ни `prefers-contrast`, ни `forced-colors` — в
  режиме принудительных цветов лист без обводки сливался бы с полом.
- **Скроллбар красился рукой** (`scrollbar-color: var(--thumb)`) вопреки
  `color-scheme`; снято вместе с ролью `--thumb`.
- Реестра осей не было; медиазапрос по неизвестному признаку никто не
  ловил.

## Что решено иначе, чем у первоисточников, и почему

- **Тема на ярусе сырья.** Figma и Curtis держат режимы столбцами на ярусе
  ролей, у примитивов столбец один. Палитра набора выпускает ступень сразу
  двухтемной (`--n-1: light-dark(…)`) — так устроены Radix Colors: одна
  ступень, два значения, и роли темы не знают. Цена — примитив не «одно
  значение без режимов»; выгода — ни одной роли с двумя блоками и ни одного
  узла, знающего о теме. Решение записано, не дефект.
- **`pointer: coarse`, не `any-pointer`** — правило проекта И15; смена на
  `any-pointer` — вопрос заказчику при первом планшете с трекпадом в
  замере.

## Чего слой не делает

Меты `color-scheme` и `theme-color`, cookie темы и проверку трёх
состояний в браузере — это проект (Next), не набор: записано в
`docs/open.md`. Масштаб 1 : 1.25 под пальцем (Spectrum) не заводится:
у набора цель и зазор растут ролью, кегль — нет.
