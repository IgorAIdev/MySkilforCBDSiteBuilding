# Формулы размера и расстояния

Файл формул скилла `scale`: только то, что считает `tools/scale.mjs`,
сторожит `tools/thresholds.mjs` и выпускает `styles/scale.css`. Каждый
раздел называет функцию, константу или переменную, которая там существует;
`check:rules` это сверяет (И218). Формулы ЦВЕТА — `palette/references/formulas.md`;
формул раскладки здесь нет: у примитивов строителя нет.

Содержание: обозначения · рампа · подстановка · ступень размера · ступень
ритма и клетка · поле · пара воздуха · зазор · коридоры · нормы · роли
текста · проситель · чужие формулы для сверки.

## Обозначения

`низ`, `верх` — концы ступени в px на двух названных ширинах `узкая`,
`широкая` (швы раскладки, у набора 560 и 1080). `тело = [т₀, т₁]` — кегль
тела на телефоне и на макете. `r = [r₀, r₁]` — отношение лестницы. `n` —
показатель ступени размера. `k` — множитель ступени ритма. `⌊x⌉ₘ` —
округление к клетке m.

## Рампа — `ramp`, `at`

Прямая через две названные ширины; на узкой даёт низ, на широкой — верх:

```
наклон (на 1vw)     = (верх − низ) / ((широкая − узкая) / 100)
свободный член (px) = низ − наклон × (узкая / 100)
clamp(низ, свободный член + наклон·vw, верх)
```

Свободный член считается по НЕокруглённому наклону и округляется после;
`at(пара, ширины, ширина)` — где рампа окажется на данной ширине, тем же
счётом. Голый `vw` без px-слагаемого не растёт при зуме 200 % (WCAG 1.4.4,
F94) — семья `bareVw` в `check:css`.

## Подстановка — `missesEnds`, `readRamp`

`readRamp` разбирает рукописную рампу обратно в низ, верх, свободный член
и наклон; `missesEnds` подставляет обе ширины и сравнивает с обещанным:
расхождение больше 0.5px — «рампа мимо своих концов». Так пойман `--sp-11`,
обещавший 100 и дававший 93.

## Ступень размера — `sizeStep`, `half`

```
размер(n) = [ half(т₀ × r₀ⁿ), half(т₁ × r₁ⁿ) ]        при n ≥ 0
размер(n) = [ half(т₀ × r₀ⁿ), half(т₁ × r₀ⁿ) ]        при n < 0
```

`half` — до половины пикселя. Отрицательные ступени — телефонным
отношением на обоих концах, иначе с r₁ > r₀ мелкий текст на макете выходит
мельче телефонного (оговорка Utopia). При теле 16 / 18 и r = 1.125 / 1.2:
xs [12.5, 14], sm [14, 16], base [16, 18], h3 [23, 31], h2 [25.5, 37.5].

## Ступень ритма и клетка — `rhythmStep`, `snap`, `RHYTHM`

```
клетка(x) = 2 при x < 16; 4 при x < 64; иначе 8                 — RHYTHM.cell
snap(x)   = round(x / клетка(x)) × клетка(x)
ритм(k)   = [ snap(т₀ × k), snap(т₁ × k) ]
            если snap(т₀ × k) ≤ RHYTHM.floor (8) — оба конца равны низу
```

Множители набора 0.25 … 6 дают при теле 16 ряд Carbon `spacing-02…12`:
4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96. Ступень не выше пола не течёт:
геометрия органа не течёт (CLAUDE.md, правило 2). Правило `клетка ритма`
спрашивает клетку и с пары, набранной числами.

## Поле — `--pad-card`

Одна ступень ритма, выпущенная в rem: `--pad-card: clamp(1rem, .7306rem +
.77vw, 1.25rem)` при ступени 4 = [16, 20] и корне `ROOT_FS` 16. Поле
растёт с буквами, которые покупатель поднял в телефоне (WCAG 1.4.4). Пол —
`RHYTHM.floor`: поле не ноль.

## Пара воздуха — `resolve`, `--air-page`

```
воздух([a, b]) = [ ритм(a).низ, ритм(b).верх ]  → рампа в px
воздух(a)      = var(--sp-a)                     → ссылка на ступень
```

Пара «через ступень» (Utopia `s-l`): `--air-page: clamp(64px, 38.15px +
4.62vw, 88px)` при ступенях 9 → 10 набора «Нынешний». Своего числа у
воздуха нет — только концы ступеней.

## Зазор — `coarse`, `TARGET`

`--gap-targets: 8px`, и второе значение той же переменной под пальцем:
`@media (pointer:coarse){ :root{ --gap-targets:16px } }`. Порог `TARGET.gap`
— 16 под пальцем (Primer `controlStack.gap`; WCAG 2.2 Target Size засчитывает
цель меньше 24 только при таком просвете).

## Коридоры — `AIR`, `GROWTH`, `AIR_TO_PAD`, `SPREAD`, `NEAR`

```
воздух к полю:   air-page.конец / pad-card.конец ≥ AIR.toPad (3) — оба конца
рост воздуха:    верх / низ ∈ AIR.growth.page  [1.33, 1.5]   — между разделами
                 верх / низ ∈ AIR.growth.other [1.25, 1.75]  — прочий воздух парой
разброс ступени: верх / низ ≤ SPREAD (2.5)                   — Utopia checkWCAG
различимость:    следующая / предыдущая ≥ NEAR (1.08)         — оба конца
```

Источники чисел — комментарии над константами в `tools/thresholds.mjs`:
замер семи люкс-магазинов на 375 и 1440, Spectrum 1 : 1.25, Utopia.

## Нормы — `TYPE`

```
нижний конец:   размер.base[0] ≥ 16, sm ≥ 14, xs ≥ 12, h2 ≥ 24  — TYPE.floor
отношение:      r₀, r₁ ∈ TYPE.ratio [1.067, 1.5]
заголовок:      h2[0] / base[0] ≥ TYPE.headContrast (1.5)
мера строки:    45…80 знаков                                    — TYPE.measure
```

## Роли текста — `auditRoles`, `TEXT`, `rolesOf`

Роль полна, когда названы `род`, `размер`, `межстрочье`, `вес`, `разрядка`,
`мера`. Пороги `TEXT`: межстрочье заголовка [1.1, 1.3], текста [1.25, 1.6];
вес ∈ {400, 500, 600, 700}; |разрядка| ≤ 0.05em, знак — по роду. Роли
объявляет первый набор (`rolesOf`): межстрочье и вес — факты типографики,
не плотности.

## Проситель — `auditReaders`, `builtNames`

Ступень живая, если её просит поле, воздух или роль хотя бы одного набора
либо читает файл стилей (`var(--sp-N` / `var(--fs-x`). `builtNames` — всё,
что выпускает строитель: объявить это число мимо него — «число на имени
строителя» (`auditSheets`).

## Чужие формулы для сверки

Utopia (`utopia-core`): размер шага `n` = `base × ratio^n` на каждом конце;
пространство = тело × {0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4, 6}; пара `s-l` = низ
`s` → верх `l`; `checkWCAG`: ступень падает при `max > 2.5·min` и `maxWidth <
5·minWidth`. Every Layout: `--s0: 1rem`, `--sN = --s0 × ratio^N` цепочкой
`calc`. Carbon type: `Xₙ = Xₙ₋₁ + (INT[(n−2)/4] + 1) × 2` от 12px. Radix:
`--space-N = N-я из 4, 8, 12, 16, 24, 32, 40, 48, 64 × --scaling`.
