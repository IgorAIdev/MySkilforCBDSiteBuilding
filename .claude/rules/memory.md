# Память работы с заказчиком

Записи о том, как заказчик работает и что он решил, лежат в `.claude/memory/`
этого репозитория и едут с ним на любую машину и в облачную сессию. Ниже —
оглавление; сами записи — файлами рядом с ним, читаются по надобности. Это
записи набора, в магазины они не едут: установщик `.claude/memory/` и
`.claude/rules/` не копирует.

@../memory/MEMORY.md

Новая запись — туда же: файл на одну запись и строка в `MEMORY.md`;
коммитится вместе с работой. Чтобы и автоматическая память Claude Code
писала в эту папку, а не на диск машины (`~/.claude/projects/…/memory`), на
каждой новой машине один раз кладётся `.claude/settings.local.json`:
`{ "autoMemoryDirectory": "<полный путь к клону>/.claude/memory" }`. Путь там
только полный, поэтому файл у каждой машины свой и в git не идёт.
