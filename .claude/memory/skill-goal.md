Goal of the kit (stated by the owner 22.09.2026): «задача скил сделать, доделать и строить витрины для cbd магазинов на next.js». Backends: Payload (content) + Vendure (commerce). The skill must (1) build such storefronts from scratch and (2) audit already-built sites for architecture and quality — "идеальные профессионально сделанные сайты".

The owner is not technical ("я не знаю терминов"): report in plain words, show results, don't hand over jargon.

Origin and core value (owner, 22.09.2026): sites had basic problems ("адаптивность херово работала"); the owner realized the site foundation was the problem and built this kit — rules, scales, layout primitives, checks, professional palette computation. `research/` holds the studies and repos the kit was derived from — it is the basis, keep it (do not slim or move it without asking).
