# Выбранные исходники компонентов

Это заготовки для адаптации в совместимом React/Tailwind v4 проекте. Код
взят из shadcn/ui, ветвь Radix, точный commit и изменения — в `../../upstream.json`.
Кнопка, dropdown действий и navigation-menu независимы; берите нужные файлы,
`cn.ts` и `LICENSE.md`. Для иконок без React доступны восемь SVG Lucide.

Зависимости: React, `radix-ui`, `class-variance-authority`, `clsx`,
`tailwind-merge`; меню используют `lucide-react`. Анимационные utility-классы
исходника предполагают совместимый набор вроде `tw-animate-css`. Проверять
существующий lockfile и выбранную версию, не устанавливать второй UI-стек.
Если проект уже использует shadcn/Radix/Base UI, расширить его компоненты.

Исходник shadcn импортировал внутренний `cn`; в сохранённых копиях это
локальный `./cn`, клиентские границы отмечены явно. Цвета, размеры, состояния
и breakpoints ещё требуют привязки к единой системе конкретного сайта.
Скопированный пример не является утверждённым дизайном.

Перед использованием:

1. Сопоставить `background`, `foreground`, `primary`, `primary-foreground`,
   `secondary`, `accent`, `popover`, `muted-foreground`, `destructive`, `border`,
   `input`, `ring` с существующими семантическими ролями обеих тем.
2. Заменить opacity-производные hover/focus, размеры, радиусы, z-index и
   длительности исходника общими ролями проекта; проверить реальные пары.
3. Проверить длинный текст кнопок: исходник содержит `whitespace-nowrap` и
   фиксированную высоту. Где возможен перенос — min-height и свободная высота.
4. `DropdownMenu` — меню команд, не универсальная замена listbox выбора шрифта
   и не меню всех страниц. Для немодального сценария передавать `modal={false}`.
5. `NavigationMenu` — готовое поведение desktop-навигации; mobile disclosure,
   маршрутные ссылки и их активное состояние собираются под реальный сайт.
6. При `asChild` сохранить ссылку ссылкой, избегать вложенных кнопок и ссылок.
   SVG внутри подписанного контрола — декоративный; icon-only контрол получает
   доступное имя. `currentColor` сохранять, не рисовать иконку повторно.
7. Проверить Tab/стрелки/Enter/Space/Escape, возврат фокуса, pointer/touch,
   reduced motion, длинные подписи, scroll/zoom, пустые и disabled-состояния.

Офлайн-копирование выбранного набора:

`node <skill>/scripts/copy-component.mjs button <новая-папка>`

Также `dropdown-menu`, `navigation-menu`, `icons`. Скрипт отказывает при
существующем назначении, не устанавливает зависимости и не меняет настройки
сайта. Папка содержит только выбранную заготовку, необходимые локальные файлы,
лицензию и происхождение. После интеграции удалить её неиспользуемые части из
экспортируемого сайта, сохранив нужные лицензии.
