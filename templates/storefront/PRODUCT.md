# Product

<!-- impeccable:product-schema 1 -->

Правда о продукте для шага 1 порядка дизайна (`CLAUDE.md`, «Дизайн делается
дизайнерскими скиллами»). Это данные, а не вёрстка: черновик собран
исполнителем по репозиторию, и каждый такой факт помечен «(выведено из
репозитория — подтвердить словом заказчика)». Подтверждённый факт теряет
пометку, отменённый — вычёркивается. Настоящий магазин из шаблона правит
этот файл под себя. Заголовки разделов — английские: их разбирает impeccable
(`.claude/skills/impeccable/reference/init.md`).

## Platform

web

## Users

- Покупатели румынского рынка; витрина говорит на трёх языках — `ro`, `en`,
  `hu` (`lib/locale.ts`). Основной язык образца — английский (слово
  заказчика 24.09.2026, записано в `lib/locale.ts`); настоящий магазин RO
  ставит румынский основным: `install.mjs --storefront --lang ro`.
- Взрослый покупатель товаров CBD — масел, капсул, косметики и средств для
  животных (полки образца: `uleiuri`, `capsule`, `cosmetice`, `animale`),
  который выбирает по силе, составу и доверию к протоколу лаборатории
  (выведено из репозитория — подтвердить словом заказчика).
- Больше половины заходит с телефона: Румыния, мобильные 54.9 % (StatCounter,
  август 2026, `docs/skills.md`), поэтому телефон — первый экран, а не
  уменьшенный (выведено из репозитория — подтвердить словом заказчика).

## Product Purpose

- Интернет-магазин товаров CBD: покупатель находит товар на полке или
  поиском, выбирает вариант, кладёт в корзину и оформляет заказ за четыре
  шага — контакт, доставка, оплата, готово (выведено из репозитория —
  подтвердить словом заказчика).
- Успех — оформленный заказ без звонка в магазин: всё, что нужно для
  решения (сила, состав, цена за единицу, срок доставки, протокол партии),
  есть на странице (выведено из репозитория — подтвердить словом заказчика).

## Positioning

- Протокол лаборатории на каждую партию, который открывается: номер партии
  на этикетке равен номеру в протоколе, и документ открывается ссылкой, а не
  обещается словом (И283; скилл `shop`, «Магазин CBD») (выведено из
  репозитория — подтвердить словом заказчика).

## Operating Context

- Доставка курьером и в пункты выдачи с поиском по городу; оплата при
  получении (с порогом суммы) или переводом (`lib/shipping.ts`,
  `lib/source/sample/commerce.ts`) (выведено из репозитория — подтвердить
  словом заказчика).
- Документы магазина — доставка и оплата, возврат, условия,
  конфиденциальность, о нас, контакты (`lib/docs.json`) (выведено из
  репозитория — подтвердить словом заказчика).

## Capabilities and Constraints

- Витрина — Next.js; товары, цены и заказы придут из Vendure, содержание — из
  Payload; сегодня источник — образец (`lib/source/index.ts`: «`live`
  (Vendure + Payload) — план 4») (выведено из репозитория — подтвердить
  словом заказчика).
- Валюта образца — евро (слово заказчика 24.09.2026, записано в
  `lib/market.ts`); настоящий магазин RO ставит леи: `install.mjs
  --storefront --currency RON`.
- Закон ЕС в интерфейсе: у скидки — самая низкая цена за 30 дней (Omnibus),
  рядом с ценой — цена за единицу (`docs/layers.md`, §5.6) (выведено из
  репозитория — подтвердить словом заказчика).
- Ни одного здравного утверждения на витрине — намеренно; категория товара
  — вопрос юристу, не вёрстке (скилл `shop`, «Магазин CBD»; ворота этапа 4 в
  `tools/stages.mjs`) (выведено из репозитория — подтвердить словом
  заказчика).

## Evidence on Hand

- Снимки, отзывы, протоколы, реквизиты фирмы — работа заказчика. Сегодня
  это образцы: флаги `CATALOG_IS_REAL`, `PRICES_ARE_REAL`, `COMPANY_IS_REAL`
  стоят в `false` (`lib/flags.ts`), протокол образца — заглушка с пометкой
  SAMPLE (`public/sample/`). Их не выдумывают и не выдают за настоящие
  (выведено из репозитория — подтвердить словом заказчика).

## Product Principles

1. Обещанное открывается: протокол, документ, адрес — ссылкой, а не словом
   (выведено из репозитория — подтвердить словом заказчика).
2. Цена честна по закону ЕС: скидка со своей низшей ценой за 30 дней, цена за
   единицу рядом (выведено из репозитория — подтвердить словом заказчика).
3. Витрина не лечит: ни одного здравного утверждения (выведено из
   репозитория — подтвердить словом заказчика).
4. Телефон — первый экран (выведено из репозитория — подтвердить словом
   заказчика).

## Accessibility & Inclusion

- WCAG 2.2 AA: контраст, цель под пальцем, имя у органа и поля, видимый
  фокус, увеличение страницы не запрещено; меряют `npm run check:craft` и
  `npm run check:seo` (выведено из репозитория — подтвердить словом
  заказчика).
- Три языка и их буквы: румынские ș ț, венгерские ő ű — шрифт выбирается с
  ними (выведено из репозитория — подтвердить словом заказчика).
